# Definition Of Done

A job is done only when its JSON specification exists, the Builder commit exists, every acceptance criterion is met, required automated tests or other executable checks pass, Reviewer records `approve`, QA records `pass` from an independent run, no critical issue remains, and the Integrator's full verification gate passes on an up-to-date branch. Builder explanations, screenshots, or changed-file lists alone are not evidence. Failing tests must be fixed or explicitly escalated; they must never be removed to obtain a pass.
