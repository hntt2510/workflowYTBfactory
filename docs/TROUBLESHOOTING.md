# Troubleshooting

- Empty model list: verify 9Router is running and reachable.
- Paid test surprise: use model-list tests before image, video, or TTS tests.
- Queue stuck in `rate_limited`: wait for `Retry-After` or reduce provider concurrency.
- CapCut draft missing: verify draft directory and Python bridge output.
- Preview missing: verify FFmpeg can read every media path.
