# Deferred Hardening

The following items are intentionally outside the first Main Happy Path V1 completion checkpoint:

- Advanced duplicate-management UX and bulk reference actions.
- Parallel or highly concurrent transcript chunk execution.
- Bulk provider execution and multi-project batch production.
- Advanced output comparison and retry dashboards.
- Automatic recovery across machines.
- Advanced asset reuse search and shared-library management.
- Advanced timeline editing and CapCut project management.
- YouTube publishing and team permissions.
- Automatic web crawling for research sources.
- External fact-checking and advanced legal or medical review.

These items must not weaken approval gates, fail-closed provider handling, artifact lineage, idempotency, or secret-safety rules in the main path.
